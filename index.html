AI Knowledge Graph Extraction from Videos

03 GitHub ↗

Xv6 Demand Paging & Swapping

Xv6's default memory management wastes physical memory on unused pages. I implemented demand paging with lazy allocation and FIFO page replacement backed by disk swap.

The hard part: Modifying OS internals - page tables, trap handlers, process lifecycle - without breaking existing functionality. Every change cascaded.

C · xv6 · Operating Systems

C-Shell

A Unix shell built from scratch to understand how process management actually works at the syscall level. Supports piping, I/O redirection, background processes, and signal handling via fork/exec.

The hard part: Getting process group management and signal propagation right. Ctrl+C should kill the foreground process, not the shell. Sounds simple until it isn't.
